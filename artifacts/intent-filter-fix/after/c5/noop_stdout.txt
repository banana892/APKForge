Rule definitions:

- `signature_replaced`: APK signature files (META-INF/MANIFEST.MF, *.SF, *.RSA/DSA/EC) replaced by re-signing; other META-INF entries are not covered.
- `certificate_replaced`: Signing certificate differs because the APK was re-signed.
- `dex_reencoded`: classesN.dex bytes differ after smali disassembly/reassembly. Class- and method-level changes are separate observations and are never noise.
- `dex_compiler_marker_removed`: R8/D8/L8 build-marker string (~~R8{...}) dropped by smali reassembly.
- `manifest_reencoded`: Binary AndroidManifest.xml bytes differ after AAPT2 recompilation. Its semantic content (permissions, components, compared attributes) is observed separately.
- `resource_table_reencoded`: resources.arsc regenerated by AAPT2. Its entries are NOT compared semantically (known limitation).
- `resource_reencoded`: res/ file recompiled by AAPT2 at the same path (binary XML re-encoding); content is not compared semantically (known limitation).
- `resource_path_canonicalized`: Collapsed resource path (res/Xy.xml) restored to its canonical res/<type>/<name> path; paired by ARSC resource identity or content hash.
- `manifest_resource_path_canonicalized`: Manifest attribute that references a resource file changes only by the same res/ path canonicalization, confirmed by a paired file rename.
