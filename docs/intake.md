# APKForge — Phase 1: Intake & Identification

The **Intake & Identification** pipeline is the entry point for all Android packages into APKForge. It accepts package inputs in various formats, verifies archive security, isolates working copies in session workspaces, extracts metadata and certificates, indexes internal files, and produces a normalized [`AndroidPackage`](file:///home/naishring/APKForge/src/apkforge/intake/__init__.py) model.

---

## 1. Pipeline Architecture

```text
Input (.apk / .apks / .xapk / split directory)
  │
  ▼
PackageDetector (Magic bytes & archive inspection)
  │
  ▼
Safe Archive Validation & Limits Check (zip-slip & bomb protection)
  │
  ▼
Workspace Isolation (Temporary directory; original input untouched)
  │
  ▼
Format Handlers:
  ├── SingleAPKHandler
  ├── APKSHandler
  ├── XAPKHandler
  └── SplitAPKHandler
        │
        ├── Streaming Cryptographic Hashes (MD5, SHA-1, SHA-256)
        ├── AndroidManifest.xml Parser (Package, Version, SDK levels)
        ├── Certificate Extractor (X.509 subject, issuer, fingerprints)
        └── Structural Inventory (DEX files, native libraries, assets)
              │
              ▼
        Normalized AndroidPackage Domain Model
```

## 2. Supported Formats

| Format | Extension / Structure | Description |
|---|---|---|
| **Single APK** | `.apk` | Standard compiled Android application package. Validated via root `AndroidManifest.xml`. |
| **APKS Bundle** | `.apks` | Container archive generated by `bundletool` containing `splits/` or multiple APKs. |
| **XAPK Bundle** | `.xapk` | Container archive commonly distributed with `manifest.json` and split APK components. |
| **Split Directory** | Directory | Folder containing multiple split APKs (`base.apk`, `config.*.apk`, `feature_*.apk`). |

## 3. Security Boundaries & Invariants

1. **Untrusted Input Invariant**: Every package is treated as untrusted data. APK code is **never executed**, native `.so` binaries are **never loaded**, and apps are **never launched**.
2. **Input Immutability**: The original input file or directory is strictly read-only and never modified in place. Work occurs only inside isolated session workspaces.
3. **Decompression Safeguards**:
   - **Path Traversal (Zip Slip)**: Any entry with `..`, absolute paths, or drive letters is rejected.
   - **File Count Limit**: Maximum entry count enforced (`max_file_count`, default 10,000).
   - **Per-File Size Limit**: Maximum uncompressed entry size enforced (`max_single_file_bytes`, default 128 MiB).
   - **Total Extraction Limit**: Maximum total uncompressed size enforced (`max_total_size_bytes`, default 512 MiB).
4. **Analysis Status Contract**: Failures and partial analyses are marked explicitly as `PARTIAL` or `FAILED` and never represented as `COMPLETE` or "clean".

## 4. Dependencies & Library Selection

In accordance with Phase 1 requirements, third-party libraries were evaluated and selected for specific roles:

| Library | Version | License | Purpose & Selection Rationale |
|---|---|---|---|
| **`androguard`** | `>=4.0.0` | Apache 2.0 | Used for parsing compiled binary Android XML (`AndroidManifest.xml`) and extracting APK signatures. Androguard is the standard, mature Python reverse-engineering tool for Android. Its usage is isolated behind [`apkforge.intake.manifest`](file:///home/naishring/APKForge/src/apkforge/intake/manifest.py) so APKForge core remains decoupled. |
| **`cryptography`** | `>=42.0.0` | Apache 2.0 / BSD | Used for cryptographic parsing of PKCS#7 / CMS signing blocks in `META-INF/*.RSA` and calculating X.509 DER certificate fingerprints. Widely audited, high-performance, and robust. |
| **`zipfile`** | Built-in | PSF | Used for low-level ZIP container access. Wrapped with safety validation in [`SafeZipExtractor`](file:///home/naishring/APKForge/src/apkforge/intake/archive.py) to prevent zip-slip and decompression attacks. |

## 5. CLI Usage

### Inspect Package

Inspect an APK, APKS, XAPK, or split directory:

```bash
apkforge inspect app.apk
apkforge inspect bundle.apks
apkforge inspect /path/to/splits/
```

### Machine-Readable Output

Generate normalized JSON adhering to the domain model:

```bash
apkforge inspect app.apk --json
```
